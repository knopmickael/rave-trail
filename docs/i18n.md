# Idiomas do jogo

O frontend suporta **português (`pt-BR`)** e **inglês (`en`)**. O seletor está na tela inicial, no login/cadastro, nas configurações do menu e no aviso de acesso pelo computador.

## Preferência e detecção

- A primeira visita usa **Automático (navegador)**. O primeiro idioma suportado em `navigator.languages`, seguido por `navigator.language`, determina a interface. Variantes como `pt-PT`, `en-GB` e `en-US` são aceitas.
- Quando nenhum idioma preferido é suportado, o fallback é inglês. Não há consulta de IP, geolocalização ou dependência externa.
- A seleção explícita tem prioridade sobre o navegador. `localStorage['rave-trail-language']` guarda somente `auto`, `pt-BR` ou `en`, por navegador/origem.
- A escolha persiste entre visitas e desconexões. `storage` sincroniza outras abas; `languagechange` atualiza o idioma detectado quando a seleção é automática.
- Valores inválidos são ignorados. Se o armazenamento estiver bloqueado, a troca continua funcionando durante a visita.

## Implementação

`frontend/src/i18n/LanguageProvider.tsx` mantém o idioma em React e expõe `useI18n()`:

```tsx
const { t, text, currency } = useI18n();

<h1>{t('Configurações')}</h1>
<p>{t('Retrato de {name}', { name: text(unit.name) })}</p>
<p>{text(ability.description)}</p>
<span>{currency(9.9)}</span>
```

- `messages.ts`: mensagens da interface, com chaves verificadas pelo TypeScript e parâmetros nomeados. Português é o texto-fonte; cada entrada fornece a tradução inglesa.
- `content.ts`: mapper do conteúdo canônico recebido da API, incluindo títulos, descrições, nomes com cargos, habilidades, histórias e prólogos. Nomes próprios como Ravi de Berdal são preservados.
- `errors.ts`: mensagens estáticas da API e falhas da interface.
- `translate.ts`: interpolação e compatibilidade com mensagens variáveis da API atual, como requisitos de missão, erros de energia e transformação. Textos desconhecidos usam o original como fallback.
- `LanguageSelector.tsx`: seletor nativo com label, navegação por teclado e indicação do idioma efetivo nas configurações.

A tradução ocorre na renderização React; não há substituição de `innerText` nem alteração do DOM fora de React. Valores interpolados são texto simples. Nomes/e-mails do jogador não passam pelo mapper.

Catálogos, estado de combate, equipe, IDs, caminhos de mídia e mensagens originais de erros permanecem canônicos. A preferência não faz parte dos contratos HTTP, progresso, sessão ou banco. Trocar idioma não refaz requisições nem reinicia telas, formulários, diálogos ou combos. `html.lang`, título da página e preços em USD acompanham a seleção.

O HTML público de descoberta e a página estática `/sobre/` continuam publicados em português; o jogo é localizado após o carregamento do frontend.

## Manutenção e testes

Ao adicionar texto na interface, cadastre uma chave em `messages.ts` e use `t`. Para novo conteúdo enviado pela API, adicione a tradução exata em `content.ts`; textos dinâmicos precisam de um padrão completo em `translate.ts`. Nunca derive IDs ou arquivos de mídia do nome traduzido.

`frontend/src/i18n/i18n.test.tsx` confere detecção, prioridade/persistência, armazenamento indisponível, sincronização entre abas, interpolação e cobertura do catálogo compartilhado. Testes de integração em `App.test.tsx` e `BattleScreen.test.tsx` validam navegação em inglês, formulários, histórias e preservação dos comandos de combate.

```powershell
npm run typecheck
npm test
npm run build
```
